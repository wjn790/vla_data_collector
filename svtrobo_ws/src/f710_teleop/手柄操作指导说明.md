# Logitech F710 手柄操作指导说明

## 前置要求：手柄模式设置

**重要：** 手柄背面开关必须拨到 **D 模式**（DirectInput），**不是 X 模式**（XInput）。
如果拨到 X 模式，按钮和轴的索引映射会全部错乱，导致操作异常。

系统已内置 X/D 模式自动检测：节点会自动识别手柄模式并在 Web 前端显示警告。
如果手柄处于 X 模式，控制会被自动禁用，Web 控制台会显示红色警告横幅，
提示将手柄背面开关拨到 D 模式。

## 快速开始

1. 确认手柄接收器已插入，设备识别为 `/dev/input/js0`
2. 确认手柄背面开关拨到 **D 模式**
3. 启动手柄控制节点
4. **首次使用必须按一次 A 按钮** 使能系统
5. 操作摇杆控制机器人移动

> 可运行 `jstest /dev/input/js0` 验证按钮/轴映射是否正确。

---

## 摇杆功能

| 控制器 | 方向 | 功能 |
|--------|------|------|
| 左摇杆 | 上 / 下 | 前进 / 后退 |
| 左摇杆 | 左 / 右 | 左平移 / 右平移 |
| 右摇杆 | 左 / 右 | 左转 / 右转 |

> 摇杆偏离中心越远，运动速度越快。摇杆回中即停止。

---

## 按钮功能

| 按钮 | 功能 | 说明 |
|------|------|------|
| **A** | 使能 | 系统上电后必须按一次 A 才能操作，急停后也需按 A 解除 |
| **B** | 急停 | 立即停止所有运动并锁定，按 A 可复位 |
| **X** | 采集开始 | 开始数据采集（首次有效，重复按忽略防止误触） |
| **Y** | 采集结束 | 停止数据采集 |
| **RB** | 升降上升 | 按住抬升升降机构 |
| **LB** | 升降下降 | 按住降低升降机构 |
| **RT** | 加速 | 每按一次，运动速度增加 0.05 |
| **LT** | 减速 | 每按一次，运动速度降低 0.05 |

---

## 数据采集

按 **X** 按钮开始数据采集时，系统会自动启动所有未运行的相机（d405_1 / d405_2 / zed），
确保采集期间所有图像数据源就绪。

按 **Y** 按钮停止数据采集时，系统会自动关闭由采集启动的相机，释放资源。

> 注意：X 按钮仅在未采集状态下生效，重复按下会被忽略以防止误触。

---

## 速度调节

- 系统启动默认速度比例：**0.25**
- 可调范围：**0.01 ~ 1.0**（绝对上限 1.5）
- 按 **RT** 加速，按 **LT** 减速，每次步进 0.05

---

## 安全须知

- **A 按钮是安全门**：开机或急停后，必须先按 A 才能恢复控制
- **B 按钮是急停**：任何时候按 B 可立即停止机器人
- 摇杆具有 40% 死区，小幅拨动不会触发运动，防止误操作
- 摇杆输入经过低通滤波处理，运动指令平滑无抖动
- **X 模式自动保护**：系统自动检测手柄模式，X 模式下控制被禁用并前端警告
- **输入超时自动停车**：手柄接收器断开、ToDesk/系统卡顿导致超过 1 秒没有真实手柄事件时，节点强制发布全 0，避免沿用最后一次摇杆速度

---

## Web 控制台与手柄模式切换

Web 控制台提供模式切换开关，两种模式互斥：

- **游戏手柄模式**（默认）：Web 键盘控制被禁用，由手柄操控机器人
- **Web 模式**：手柄输入被忽略，通过网页键盘控制机器人

切换操作在 Web 控制台界面完成，无需重新启动节点。

## 默认参数（可通过配置文件修改）

| 参数 | 当前值 | 说明 |
|------|--------|------|
| 最大线速度 | 0.4 m/s | `velocity.max_linear` |
| 最大角速度 | 0.4 rad/s | `velocity.max_angular` |
| 角速度倍率 | 5.0 | `velocity.angular_scale` |
| 速度比例上限 | 1.0 / 1.5 | `speed_scale.max` / `speed_scale.hard_max` |
| 初始速度比例 | 0.25 | `speed_scale.initial` |
| 摇杆死区 | 0.4 | `deadzone` |
| 升降速度 | 500 RPM | `lift.speed` |
| 发布频率 | 25 Hz | `publish_rate` |

配置文件路径：`config/f710_teleop.yaml`
